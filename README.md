# Spring Trap

A fun, little mod that can cause chaos, or actually be a practical defense technique in both single player and PvP. Spring Trap looks like an oak pressure plate when you place it down, but when a creature, player or even you step on it, it launches them up to 25 blocks into the air! 

## Install

Grab the JAR from [Releases](https://github.com/adamsilfven/springtrap/releases) and drop it in your `mods` folder. You'll need Minecraft 1.20.1, Forge 47.x, and Java 17.

## Crafting

Put slimeballs on either side of redstone. Under that, put iron ingots on either side of a piston.

## Build

Run `./gradlew build` with Java 17. The JAR goes in `build/libs/`. Run `./gradlew runGameTestServer` to check the launch and reset.
