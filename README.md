# Spring Trap

It's a pressure plate with a spring under it. Step on it and you'll go flying about 20 blocks up in a random direction. There's a puff of smoke and a boing.

## Install

Spring Trap 1.0.2 is for Minecraft 1.20.1 on Forge. Drop `springtraps-1.0.2-forge-1.20.1.jar` into your `mods` folder.
